ReportAPI Self-Hosted is installed.

{{- if .Values.postgresql.enabled }}
Postgres is deployed by this chart (the bundled Bitnami postgresql
subchart) at {{ .Release.Name }}-postgresql:5432.
{{- else }}
Postgres is NOT deployed by this chart (postgresql.enabled=false) —
point envSecret/env at an externally managed instance.
{{- end }}
{{- if .Values.redis.enabled }}
Redis is deployed by this chart (the bundled Bitnami redis subchart,
standalone architecture, no auth) at {{ .Release.Name }}-redis-master:6379.
{{- else }}
Redis is NOT deployed by this chart (redis.enabled=false) — point
env at an externally managed instance.
{{- end }}

{{- if .Values.migrations.enabled }}
Schema migrations run automatically as a post-install/post-upgrade Job
({{ include "reportapi.fullname" . }}-migrate). The api/worker/beat pods
may restart a few times on a fresh install while that Job waits for
Postgres and applies migrations — this is expected and self-resolves;
check its status with:
  kubectl logs job/{{ include "reportapi.fullname" . }}-migrate
{{- end }}

Set envSecret.CONFIG_API_TOKEN before installing in production — every
API route except /health requires it, and the chart ships no default.

Get the API URL:
  kubectl port-forward svc/{{ include "reportapi.fullname" . }}-api 8000:{{ .Values.api.service.port }}

{{- if .Values.configUi.enabled }}
Get the config UI:
  kubectl port-forward svc/{{ include "reportapi.fullname" . }}-config-ui 8080:{{ .Values.configUi.port }}
{{- end }}
